# Truss PINN Design Spec — Pratt 桁架预应力形变与模态分析

**日期**：2026-09-20
**状态**：已与用户对齐（七维度 + 架构方案 B + sym 符号推导）
**交付位置**：`examples/structural_mechanics/truss_pinn/`

## 1. 目标

构建有限元（FEM）参考求解器与 PINN 代理模型，用于预测 Pratt 桁架桥在参数化载荷
范围内的静力形变与前 3 阶预应力固有模态（频率 + 振型）。

物理链条：

```text
载荷参数 (n, θ, P) ──静力平衡──▶ 节点位移 u(P) ──轴力──▶ N_e(P)
   ──几何刚度──▶ K_G(P) ──特征值问题──▶ (ω_i(P), φ_i(P)), i=1..3
```

核心物理：预应力效应——拉载荷刚化（频率升高）、压载荷软化（频率降低）。
载荷是模态的参数，这是"载荷范围内的模态预测"成立的物理基础。

## 2. 问题定义

### 2.1 几何（固定）

经典 3 节间 Pratt 桁架桥，跨度 6 m、节间 2 m、桁高 1 m。

节点索引（单一约定）：下弦 `0,1,2,3`（x = 0,2,4,6 m，y = 0），上弦
`4,5,6`（x = 1,3,5 m，y = 1 m）。共 7 节点（N=7）。

连接表（11 杆，M=11）：

- 下弦 3 杆：(0,1), (1,2), (2,3)
- 上弦 2 杆：(4,5), (5,6)
- 端斜杆 2 杆：(0,4), (3,6)
- 竖杆 2 杆：(1,4), (2,5)
- 内斜杆 2 杆（Pratt 斜杆向跨度中心下倾）：(1,5), (2,6)

每个节间恰好一个三角形，三角化完备，无零长度/共线退化单元。连接表在
`helpers/geometry.py` 中冻结，FEM 与 PINN 共用（单一事实来源）。

支座：节点 0 为 pin（x、y 固定），节点 3 为 roller（仅 y 固定）。
自由节点：1, 2, 4, 5, 6（受载候选集合）。

### 2.2 材料与截面（突出预应力效应的调参结果）

尼龙 6/6：E = 3 GPa，ρ = 1150 kg/m³；实心方杆截面 A = 1e-4 m²
（32×32 mm，I = A²/12 ≈ 8.3e-10 m⁴）。

> Errata（2026-09-21）：上文 "32×32 mm" 标注为笔误——A = 1.0e-4 m² 对应
> 10×10 mm 方截面。代码（`geometry.py`）与 README 使用正确值（A = 1.0e-4 m²
> 不变，仅标注更正）；物理量不依赖标注，仅 A 参与计算。

量级检查（P_max 初按 2 kN 估计，最终由稳定性扫描定）：

- 应力：σ = P/A ≈ 20 MPa < 屈服 ~80 MPa（安全系数 ~4）
- 预应力强度：N/(EA) = 2e3/(3e9·1e-4) ≈ 6.7e-3 → 频率变化可达百分之几
- 单杆欧拉屈曲载荷 P_E = π²EI/L²（对角杆 L ≈ 2.23 m）≈ 5e-3 N——
  远低于工作轴力量级。这是细长铰接杆的固有属性，不是参数错误。

**线性化有效性判据**：预应力模态是切线刚度 (K+K_G) 上的广义特征值问题，
线性理论只要求 (K+K_G) 在整个载荷范围内保持正定（结构整体不失稳），
与单杆欧拉临界值无关。**P_max 以数值扫描界定**：扫描载荷找到
(K+K_G) 最小特征值首次过零的 P_crit，取 P_max = 0.3·P_crit
（3 倍余量避开屈曲边界）。若该 P_max 下预应力频率变化 < 1%，
回到设计循环调参（增大细长比或降低 E）。

**截面/载荷参数在 §3 自证测试通过前不冻结**：「拉升压降」符号检查与
「(K+K_G) 正定性扫描」共同构成参数冻结关卡。

### 2.3 载荷参数化

参数三元组 `(n, θ, P)`：

- `n`：受载节点，从 5 个自由节点 {1,2,4,5,6} 中选一，one-hot 5 维
- `θ`：载荷方向角，[0, 2π) 连续，输入取 (cos θ, sin θ)
- `P`：幅值，[−P_max, +P_max] 连续（正负覆盖拉/压两个预应力方向）

网络输入（8 维）：`one-hot(n) ⊕ (cos θ, sin θ, P/P_max)`（归一化）。

载荷向量 f ∈ ℝ^14：仅受载节点 n 对应的两个 DOF 非零，
`f[2n] = P·cosθ, f[2n+1] = P·sinθ`。

### 2.4 输出与验收标准

- 形变：7 节点位移场（支座为零，网络实际输出 5 个自由节点的 10 维）
- 模态：前 3 阶固有频率 ω_i 与 M-归一化振型 φ_i（各 10 维）
- **验收**：
  - 位移场相对 L2 误差 < 5%（对独立测试载荷工况集）
  - 前 3 阶频率相对误差 < 2%
- 测试集：FEM 在独立采样的载荷参数上生成（与训练锚点不重叠）

## 3. FEM 参考求解器（`helpers/fem.py`）

线性弹性 2D 铰接桁架，平面杆单元（每节点 2 DOF）：

- 单元刚度阵（全局坐标）：标准 4×4 形式，(EA/L) 乘方向余弦二次型
- 一致质量阵：轴向一致质量局部形式 `ρAL/6·[[2,-1],[-1,2]]`，经方向余弦
  变换到全局 4×4（实现按标准公式）
- 支座：划行划列消除 → K_red, M_red ∈ ℝ^(12×12)
- 静力：`torch.linalg.solve`，批量（B × 12 × 12）
- 轴力：`N_e = (EA/L_e)·(c·Δu_x + s·Δu_y)`，拉为正（N_e > 0 → 刚化）
- 几何刚度：2D 杆横向几何刚度（N_e/L_e 二次型，仅横向项）
- 预应力特征值问题：`(K_red + K_G,red(P))·φ = ω²·M_red·φ`，
  经 M_red 的 Cholesky 化为标准对称问题后 `torch.linalg.eigh`
- **自证测试**（train.py 启动时自动运行，失败阻断训练）：
  1. 单杆拉伸闭式解对比
  2. 无预应力整体基频与解析近似对比（能量法上下界）
  3. 特征向量 M-正交性检验 `Φᵀ M Φ = I`
  4. 拉载荷频率升高、压载荷频率降低（物理符号检查）
  5. 整个 P 范围内 (K+K_G) 最小特征值 > 0（线性化有效性）
  6. sym 符号残差 vs 手写 K·u 逐元素一致性检查（同一工况）
  7. 与 scipy.sparse 求解器交叉验证（scipy 可选依赖，缺失时跳过）

## 4. PINN 设计

### 4.1 网络结构

`physicsnemo.models.mlp.FullyConnected`：

- 输入 8 维（one-hot(n) 5 + cosθ, sinθ, P_norm 3）
- 输出 43 维 = 位移 10（自由节点）+ 频率 3（log ω）+ 振型 30（3 × 10）
- 默认超参：layer_size 128，num_layers 4，silu，先按默认跑基线

### 4.2 损失函数

训练每批采样载荷工况（n 离散均匀、θ 与 P 连续均匀）：

1. **平衡残差**（物理，主信号）：`‖K_red·û − f_red‖²`，K_red 由
   `physicsnemo.sym` 符号推导 → `SympyToTorch` 编译的可微表达式组装。
   符号层推导每根杆的应变能 `U_e = (EA/2L)·(c·Δu_x + s·Δu_y)²`，
   残差 = ∂(Σ U_e)/∂u —— 即 K·u（能量法残差，与 FEM 的 K 同源）。
   符号表达式以节点位移符号为自由变量。
2. **锚点监督**：64 个 FEM 载荷工况的位移解（网格覆盖 n × sign(P) ×
   |P| 档位，θ 取典型值），`‖û − u_FEM‖²`
3. **模态监督**（锚点工况）：FEM 特征值解直接监督 (ω_i, φ_i)；
   物理特征值残差 `‖(K+K_G(P))·φ̂_i − ω̂_i²·M·φ̂_i‖²` 作为非锚点工况正则
4. **振型归一**：网络振型输出经 M-归一化（φ̂ ← φ̂/√(φ̂ᵀ M φ̂)），
   相位固定（绝对值最大分量取正），消除尺度/符号不定性
5. **权重**：λ_eq = 1，λ_sup = 100，λ_mode = 10（固定，不自适应）
   ——锚点初期主导，物理残差保证非锚点工况的物理一致性

**排序陷阱与对策**：特征值残差对任何特征对均为零，无法单独区分最低
3 阶。对策：锚点工况直接监督（含排序），非锚点只用残差正则；振型监督
用 M-正交化后的 FEM 振型（相位歧义已消除）。

### 4.3 数据流

```text
geometry.py ──▶ fem.py ──▶ 锚点数据 (64 工况: u, ω, φ)
     │              │
     │              └──▶ 测试数据（独立采样 200 工况）
     └──▶ truss_pde.py (sym 符号残差)  ──▶ train.py
                                             │
                              evaluate.py ◀──┘ (对比 + 图表 + 误差报告)
```

## 6. 验证计划

1. **FEM 自证**（§3 所列 7 项），失败则阻断训练
2. **PINN 训练收敛**：损失曲线 + 锚点工况拟合
3. **验收测试**：200 个独立测试工况，位移 L2 相对误差 < 5%、
   前 3 阶频率相对误差 < 2%；报告逐工况误差分布（最大/中位/P95）
4. **物理一致性检查**：预测的 ω(P) 曲线趋势（拉升压降）与 FEM 曲线对比
5. **可视化**：形变对比图（FEM vs PINN 叠加）、频率-载荷曲线族
   （不同 n、θ 下 ω_i(P)）

## 7. 风险与缓解

| 风险 | 缓解 |
|---|---|
| sym 符号→torch 编译表达式与手写 K 不一致 | 自证测试 6：逐元素一致性检查 |
| 模态排序歧义 | 锚点直接监督 + 残差仅作正则 |
| 预应力效应过弱导致 ω(P) 曲线平缓 | 已调参（尼龙+细截面）；曲线变化 < 1% 则回设计循环 |
| 载荷范围进入屈曲边界非线性区 | P_max = 0.3·P_crit（稳定性扫描界定），自证测试 5 把关 |
| T4 上训练不收敛 | FullyConnected 默认超参起步；失败则加 skip_connections 或调 lr |
| 载荷加在支座节点上无意义 | 受载集合 = 5 个自由节点（采样层保证） |
