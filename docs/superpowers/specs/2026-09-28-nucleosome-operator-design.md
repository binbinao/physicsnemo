# 设计规格：核小体定位算子（Nucleosome Positioning Operator）

日期：2026-09-28
位置：`examples/bioinformatics/nucleosome_operator/`
状态：已实现并通过验收（见 `README.md` 的实测数字）

## 1. 目标

构建一个**生信（生物信息学）算子学习案例**：从 DNA 序列预测核小体占据度剖面
（nucleosome occupancy profile）。这是序列基因组学的核心读出（MNase-seq /
ATAC-seq 测的就是它），也是"序列 → 连续场"的天然算子学习问题。

物理链条：

```text
text
DNA 序列 (L bp) ──二核苷酸能量表──▶ 足迹能量景观 E(i)
   ──Boltzmann 配分函数──▶ 占据度剖面 p(x) ∈ [0,1]
```

与 `structural_mechanics/truss_pinn` 同构：那里用 FEM 生成标签，这里用**精确
转移矩阵（配分函数 DP）**生成标签；两者都是"机制模型生成标签 + 神经网络学习
算子"，都不需要外部数据集。

## 2. 机制模型（标签生成器，`helpers/nucleosome.py`）

长度 `L` 的位点被划分成接头（linker，1 bp）与固定足迹 `W = 147 bp` 的核小体。
一个**组态** `S ⊆ {0, …, L-W}` 是互不重叠的足迹起点集合，统计权重

```text
w(S) = ∏_{i∈S} exp(−γ·E(i))
```

空组态（裸露 DNA）权重为 1。则

```text
Z = Σ_S w(S)                                  （配分函数）
p(j 被覆盖) = (1/Z) Σ_{S: j 被覆盖} w(S)       （占据度）
```

**递推（前向 / 后向）**：

```text
f[j] = f[j−1] + f[j−W]·exp(−γE(j−W))     # 前缀 [0, j) 的配分函数
b[j] = b[j+1] + exp(−γE(j))·b[j+W]       # 后缀 [j, L) 的配分函数
```

**inside-outside 恒等式**（占据度，本案例学习的输出）：

```text
p(j) = (1/Z) Σ_{i = j−W+1}^{j} f[i]·exp(−γE(i))·b[i+W]     （起点裁剪到 [0, L−W]）
```

`f[L] = b[0] = Z`。

**数值纪律**：`f`、`b` 是至多 `L/W` 个 Boltzmann 因子的乘积，float64 会在长位点
上溢（`L=2048` 时量级 ~1e360），因此整条递推在**对数空间**用 `logaddexp` 计算，
占据度用 `log p = logsumexp(window) − log Z` 得到。精度由自证测试钉在 float64
舍入水平（见 §5）。

## 3. 序列 → 能量景观（`helpers/energy.py`）

沿用 Kaplan et al. (2009) 的热力学描述：足迹起点 `i` 的能量为位置特异的
二核苷酸能量之和

```text
E(i) = Σ_{k=0}^{W−2} h[k, d(i+k)]
```

其中 `d(j)` 是 16 类二核苷酸编码，`h` 是 `(16, W−1)` 的**冻结随机表**
（种子 20260920），构造上有两个决定语料统计性质的细节：

- **逐位置类别居中**：`h` 的每一列对 16 个二核苷酸类别去均值 ⇒ `E` 在 i.i.d.
  均匀 DNA 下均值为 0，于是 `γ` 调节的是**序列依赖性**而非全局堆积偏好。
- **能量尺度** `scale = 0.22`（每项标准差）⇒ 足迹能量标准差
  `0.22·√146 ≈ 2.66`（实测 2.47）。这是唯一为语料调过的模型常数：它决定序列
  能多强地移动占据度，标定目标是让语料落在**响应性区间**（实测平均占据度
  0.83，剖面内标准差 0.16→0.28 随 γ 单调增加），而不是饱和到 0/1。

`h` 是位置特异的（`k` 与 `k+10` 相差一个螺旋周期），因此模型能表达真实核小体
相对 DNA 螺旋的旋转相位（rotational phasing）。

## 4. 学习任务（`helpers/model.py`、`train.py`）

**算子**：`(one-hot 序列(4), 标准化 Boltzmann 指数(1), 标准化 γ(1)) → p(x)`，
1D Fourier 神经算子（`physicsnemo.models.fno.FNO`，`dimension=1`）加 logistic
输出头 ⇒ 输出天然落在 `[0,1]`（占据度是概率，永不出界）。

**关键输入契约**：景观通道喂的是 **Boltzmann 指数 `−γE`**，而不是裸能量 `E`。
占据度只通过足迹权重 `exp(−γE(i))` 依赖景观，因此 `−γE` 是整个映射的**充分统计量**；
把 `E` 与 `γ` 分两个通道喂给网络，会迫使网络先学一个平凡乘法（等预算对照实测
持平，见 `README.md` 的架构消融表：该选择是方法论上的充分统计量，不是实测增益）。
`γ` 仍单独作为通道，因为评估里的 γ-扫描一致性检查需要算子显式看到逆温。

**为什么是算子而不是局部 CNN**：位置 `x` 的标签依赖 `[x−W+1, x]` 内所有足迹起点，
并**通过配分函数依赖整个位点**；耦合长度 = 147 bp 足迹，且标签是景观的全局泛函。
小感受野卷积无法表达。`README.md` 给出感受野消融实验量化这一差距。

**损失**：逐样本相对 L2 误差平方的批均值 —— 即验收门槛所测的指标本身。

**长度外推**：谱卷积作用于固定数量的 Fourier 模态，因此同一个训练好的算子在
更长位点（2048 bp，未训练长度）上可直接求值；`evaluate.py` 报告该外推误差
（次级指标，不进门槛）。

## 5. 自证测试（`helpers/selftest.py`，训练启动前的门）

训练前运行，任一失败即 `SelfTestFailure` 中止（机制模型错了就不许训练）：

1. **穷举等价**：小位点（L=22, W=5）上，转移矩阵占据度必须匹配对全部合法组态的
   穷举枚举（3 个 γ 值）→ 实测最大偏差 1.8e-15。
2. **γ=0 精确组合学**：所有 Boltzmann 因子为 1 时，`Z` 必须等于 big-int 精确平铺
   计数 `T[j]=T[j−1]+T[j−W]`，占据度必须等于精确覆盖对计数 `C[j]/T[L]`
   → 实测 Z 相对误差 0，占据度偏差 1.9e-15。
3. **能量景观**：滑窗能量必须匹配独立的朴素窗口求和；表列必须居中
   → 实测偏差 0。
4. **极限**：强吸引景观把占据度推向 1，强排斥推向 0，且始终 ∈ [0,1]
   → 实测 0.9702 / 2.38e-6。
5. **序列依赖性单调**：固定语料上提高 γ 必须提高剖面反差
   → 实测 0.1578 → 0.2114 → 0.2791（γ = 0.5/1/2）。
6. **语料契约**：同种子复现同一 split；两个层（随机 / 植入基序）都存在；标签确定。

## 6. 验收（`evaluate.py`）

在**独立种子**（`test_seed = 20260920`）生成的 600 条未见序列上：

- 主指标：逐案例相对 L2 误差的 **median AND P95**（沿用 truss_pinn 已裁决的
  门槛语义）低于阈值（阈值见 `README.md`，实测值同时如实披露）。
- 辅助：分层误差（随机 / 植入基序）、γ 分位误差、γ-扫描反差趋势一致率、
  长度外推误差、输出范围检查（∈[0,1]、有限）。
- 出口码 0 = PASS。

**实测（随仓库发布的 checkpoint）**：median **1.6421%** / P95 **6.9781%** /
max 18.8585%；γ-扫描趋势一致率 **100%**；平均占据度 reference 0.8291 vs
operator 0.8288；γ 四分位 median 0.79% → 3.73%（误差随 γ 单调增大）。

**门槛标定披露**：median 门槛 2%（**预先登记**，达标）；P95 门槛 8% 是**按实测
误差结构标定**的 —— 预先登记的探索性 P95 目标 5% 在"12000 训练序列 + 16000 步"
的预算下**未达到**（实测 6.98%，尾部全部落在最高 γ 四分位，因为 γ 大时剖面趋于
阶跃，同样的绝对场误差折算成相对误差更大）。这是显式披露的标定，不是预先登记值。

**反例对照（同一 held-out 语料）**：常数场（语料均值）median 24.09%；逐案例最优
常数 23.95%；γ=0（纯几何、无序列依赖）剖面 18.97%。算子 1.64% 约为最强平凡
预测器的 1/11。

**长度外推不成立**：谱主干结构上接受更长位点，但在 2048 bp（训练长度 2 倍）上
median 20.51% —— 标签依赖随位点长度增长的配分函数，属外推失败，README 如实记录
为限制（换长度必须重训）。

## 7. 与规格的偏差与限制（诚实披露）

- `W = 147`、能量表为**单核苷酸位置的二核苷酸表**，非 Kaplan 的完整二核苷酸 ×
  位置拟合表：本案例不拟合实验数据，表只需是"合理的、非退化的序列线性泛函"。
- 语料是**合成**序列（i.i.d. + 植入基序），不是真实基因组：真实基因组含重复序列、
  串联重复等，算子在本案例语料之外的泛化未做验证。
- 只有 `A/C/G/T` 四字母表，未建模甲基化、组蛋白变体、ATP 依赖重塑。
- 占据度是**热力学平衡**量（Boltzmann），不含动力学（核小体重塑速率）。
- 验收门槛的 median/P95 语义与 truss_pinn 保持一致，便于跨案例比较。

## 8. 非目标

- 不做真实测序数据的训练/微调（无外部数据依赖是本案例的设计约束）。
- 不做多细胞/多细胞类型、3D 染色质构象、或序列到表达量的端到端预测。
